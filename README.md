# Zotero Web

在 Zotero 右侧打开网页，顺手完成划词、题录与 PDF 全文翻译。

Zotero Web 是一个 Zotero 侧边栏插件，当前版本为 `0.2.4`。它把网页浏览和文献翻译放在同一个工作区域里：网页模式用于访问网页或网页版 AI，插件本身不会调用模型 API；翻译模式支持选中文字、题录以及 PDF 全文的翻译与总结。

翻译模式可以使用免 Key 的 Bing / Google，也可以接入 OpenAI 兼容的大模型。插件不提供内置模型额度，也不会绕过网页平台的登录或会员限制。

## 界面与两种模式

侧边栏顶部可在“网页”和“翻译”之间切换。切换模式不会替换侧边栏中的网页内容，也不要求先打开某个文献。

### 网页模式

网页模式提供以下控件：

- 后退、前进、刷新与主页。
- Prompt 菜单：复制已有的历史 Prompt。
- 地址栏：输入网址后访问页面。
- 隐藏：收起侧边栏，并保留当前网页。

网页模式本身不接入翻译或大模型请求。你在内嵌网页中与网页版 AI 的交互，仍然受该网站自己的账号、使用条款和网络环境约束。

### 翻译模式

翻译面板顶部有三个按钮：

| 按钮 | 用途 |
| --- | --- |
| 翻译选中 | 翻译鼠标选中的文字 |
| 翻译 PDF 全文 | 翻译当前 PDF 的全文 |
| 翻译并总结 PDF | 翻译全文并生成总结 |

面板会显示任务进度、原文/译文、题录信息和总结。停止或失败的任务会保留已经生成的部分内容，便于检查或继续复制。

## 翻译入口

| 入口 | 处理对象 | 行为 |
| --- | --- | --- |
| 翻译面板中的“翻译选中” | 鼠标选中的文字 | 面板显示原文与译文，支持 PDF 阅读器、网页侧边栏和翻译面板本身 |
| 文献列表右键 →“翻译” | 题录或 PDF | 提供“翻译题录（标题和摘要）”“翻译 PDF 全文”“翻译并总结 PDF 全文” |
| 文献列表工具栏“译” | 当前文献的 PDF | 一键执行 PDF 全文翻译并总结 |
| PDF 阅读器工具栏“译” | 当前 PDF | 一键执行 PDF 全文翻译并总结 |
| 向翻译面板拖入 | Zotero 条目或外部 PDF | 自动执行全文翻译并总结；条目没有本地 PDF 时回退为题录翻译 |

### 翻译选中的文字

先用鼠标选中文字，再点击“翻译选中”。PDF 阅读器、网页侧边栏和翻译面板内的选择都可用于翻译；结果显示为原文与译文。“翻译选中”只处理选中的文字，不会触发 PDF 全文翻译。

### 拖入条目或文件

把 Zotero 条目或外部 PDF 拖到翻译面板，会默认执行“全文翻译 + 总结”。

- 外部 PDF 会临时导入 Zotero 以提取文本，提取完成后自动删除。
- 外部临时导入的 PDF 不写入翻译缓存。
- 若拖入的条目没有本地 PDF，会改为翻译题录（标题和摘要）。

## PDF 翻译缓存

成功完成的 PDF 全文翻译会写入本地缓存，方便下次直接查看。

- 位置：Zotero 数据目录下的 `zotero-web-translations.json`。
- 容量：最多保留最近 20 份 PDF 结果，超出后淘汰较旧的记录。
- 翻译 PDF 全文：如果该 PDF 有缓存，第一次点击加载缓存，不重新翻译；再次点击才重新翻译并覆盖缓存。
- 翻译并总结 PDF：优先复用已缓存的译文，只生成总结，不重新翻译；如果缓存里已有总结，直接显示。没有缓存译文时才执行翻译+总结。
- 不自动执行：打开翻译页本身不会自动加载或翻译全文，只有手动点击 PDF 翻译按钮才会处理。
- 不缓存：外部临时导入的 PDF 处理完成后会删除，不会写入缓存。
- 内容：缓存包含原文、译文与总结，也供“复制全文到网页 AI”和保存笔记使用。
- 清理：退出 Zotero 后删除 `zotero-web-translations.json` 即可。

缓存保存在本机 Zotero 数据目录中，插件不会上传该缓存文件。

## 结果操作

结果区下方提供四个操作，实际可用项会随结果类型变化：

| 按钮 | 作用 |
| --- | --- |
| 复制总结 | 将当前总结放入系统剪贴板 |
| 复制译文 | 复制当前译文；题录结果会包含标题和摘要译文 |
| 保存为笔记 | 将当前结果保存为 Zotero 笔记 |
| 复制全文到网页 AI | 仅 PDF 结果可用；复制论文全文与提示词，并切回网页模式 |

“复制全文到网页 AI”不会自动发送内容，需要你粘贴到网页端后由对应网站处理。

## 安装与升级

需要 Zotero `9.0.0` 至 `10.0.x`，安装包为 `dist/zotero_web_0.2.4.xpi`。

1. 在 Zotero 中打开“工具 → 插件”。
2. 点击插件页右上角的齿轮按钮，选择“从文件安装”。
3. 选中 `dist/zotero_web_0.2.4.xpi`，按提示重启 Zotero。
4. 如果之前安装过旧版，建议先卸载旧版并重启，再安装当前 XPI，避免 Zotero 继续使用旧缓存。

## 翻译设置

在 Zotero 插件设置中打开 `Zotero Web` 的“翻译设置”区域，字段按以下顺序排列：

| 位置 | 设置项 |
| --- | --- |
| 第一行 | 目标语言、翻译引擎、大模型预设 |
| 第二行 | API 地址、API Key、模型名称 |
| 第三行 | 全文最大字符数 |
| 下方 | 测试、保存设置 |

- 目标语言：简体中文、繁體中文、English、日本語、한국어。
- 大模型预设：DeepSeek、OpenAI、硅基流动（SiliconFlow）、Ollama、LM Studio。
- 全文最大字符数：默认 `120000`，允许设置为 `4000` 至 `1000000`；全文超过该值时会被截断。
- 测试：按当前配置执行一次测试；修改设置后，点击“保存设置”生效。

翻译引擎的行为如下：

| 引擎 | 说明 |
| --- | --- |
| 智能选择 | 已有可用的大模型配置时使用大模型；否则使用免费 Bing，Bing 失败时回退 Google |
| 微软 Bing 翻译（免费） | 不需要 API Key，通过 Bing 翻译网页接口工作 |
| Google 翻译（免费） | 不需要 API Key；部分网络环境需要代理或 VPN |
| AI 大模型（OpenAI 兼容） | 文本发送到所填 API 地址；使用云端服务时通常需要 API Key |

本版设置页不再包含 Prompt 编辑器；侧边栏网页模式中的 Prompt 菜单只用于复制已有历史 Prompt。

## 免费引擎说明

免 Key 不等于离线。微软的免费入口通过 Bing 翻译网页接口工作，早期 Edge 鉴权端点已经退役，接口也可能随 Bing 页面调整而暂时失效。Google 在部分网络环境下需要代理或 VPN。

免费引擎适合一般性的短句、题录和全文翻译。免费模式下的总结是本地抽取式摘要，主要依据句子筛选与词频生成，并不真正理解论文语义，结构化和要点质量有限。如果需要研究问题、方法、主要发现、贡献与局限等结构化总结，建议配置 AI 大模型。

## 隐私与限制

- 使用免费引擎时，待翻译文本会发送到 Bing 或 Google；智能选择回退时会发送到 Google。
- 使用 AI 大模型时，文本会发送到你填写的 API 地址，并需遵守对应服务商的隐私和计费规则。
- 翻译请求直接发往所选服务，插件不另设中转服务器。
- API Key 以明文形式保存在 Zotero 偏好中；输入框隐藏字符并不代表加密存储。
- PDF 缓存保存在本机 Zotero 数据目录，包含原文、译文和总结；需要时请手动清理。
- 扫描版或纯图片 PDF 没有可提取的文字层，需要先做 OCR；插件不内置 OCR。
- 插件不绕过网页平台的登录、会员或使用限制；网页可访问性取决于平台和网络环境。

## 故障排查

| 现象 | 可以尝试 |
| --- | --- |
| Bing 翻译失败、鉴权失败或返回格式异常 | Bing 页面接口可能改版或临时限流；稍后重试，或改用 Google / AI 大模型 |
| Google 翻译超时或无法连接 | 当前网络可能需要代理或 VPN；也可切换到 Bing 或已配置的大模型 |
| PDF 提示未能提取到文字 | 确认 PDF 是本地且可正常打开的文件；扫描版请先 OCR |
| 大模型返回 401 / 403 | 检查 API Key、API 地址和模型名称是否与服务商要求一致 |
| 大模型请求超时 | 检查网络与接口地址；可适当降低“全文最大字符数”或更换可用模型后重试 |
| 想清除已缓存的 PDF 结果 | 退出 Zotero 后删除数据目录中的 `zotero-web-translations.json`，再重新启动 |
